# Расширения XMPP от Яндекса

**[Читать](https://github.com/jbbxru/xmpp-extensions/wiki)**

Это неофицальная документация к проприетарным расширениям XMPP,
используемых в [Я.Онлайн](https://web.archive.org/web/20131022091903/http://wiki.jrudevels.org/Ya.Online).

Документация основана на результатов изучения [исходников модуля «Чат»](https://github.com/jbbxru/yachat),
который, будучи форком [известного клиента «Psi»](https://psi-im.org/), является открытым и обязан
распространяется под [GNU GPLv2 с Qt Linking Exception](https://github.com/mblsha/yapsi-psi-snapshot/blob/master/COPYING).
_(даже, несмотря на то, что в публичных архивах исходного кода под сборку и установку клиента на Linux-системах,
Яндекс заменили его на своё лицезионное соглашение, которое несовместимо с GPL)_

Данная документация распространяется под лицензией [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
